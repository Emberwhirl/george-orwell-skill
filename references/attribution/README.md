# Attribution evidence (secondary)

This directory is **not** a collection of Orwell's own writings.

Records here document how quotations circulate under Orwell's name: genuine
quotations, paraphrases sold as quotations, quotations with no located primary
source, demonstrated misattributions, disputed attributions, and wording
altered in transmission.

The four seed records match the misattribution blacklist in `SKILL.md`.

## Epistemic rule

**Absence from the checked primary corpus is not proof that Orwell never said
something.**

Use `not_found_in_checked_corpus` when the wording was searched in the texts
used to build this skill and was not found.

Use `demonstrated_misattribution` only when independent evidence identifies
another author, a later first appearance, or an equivalent positive case that
the wording is not Orwell's.

Do not promote a `not_found_in_checked_corpus` record to
`demonstrated_misattribution` merely because a search failed.

## Classification

Every YAML file here must set `classification: secondary`. These records are
not `[PRIMARY]` Orwell texts.
